This directory contains all scripts, to find and extract the s-locus across different genome assemblies:

1) Run the Find_reverse_same_strand_slocus.sh script to find the contig which covers the S-locus (defined as sequence between ARK3 and B80), additionally, contigs will be all reversed to the same strand for better assessment of blast results

2) Run Find_extract_slocus_coordinates.sh to get the coordinates on reversed strand, and set unmber of flanking basepairs with which you want to extract the s-locus from you contigs
